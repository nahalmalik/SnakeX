# 🐍 SnakeX

### A Classic Snake Game Built with Flutter

SnakeX is a classic Snake game developed using **Flutter** as a semester project. The game combines traditional Snake gameplay with customizable colors and multiple control modes, giving players different ways to interact with the game.

---

## 📖 Description

SnakeX is a small Flutter-based game project created to explore mobile application development, interactive UI design, touch controls, and game logic using Dart and Flutter.

The game currently includes:

* 🎨 Fully customizable colors
* 🎮 Four different control modes
* 📱 Touch-based interaction
* 🐍 Classic Snake gameplay
* ✨ Custom game interface

The project was developed as a **semester project** with a focus on learning and implementing Flutter in an interactive application.

---

## 🎮 Control Modes

SnakeX provides four different control modes:

### 1. Tap on Buttons — Default Mode

Use the on-screen directional buttons to control the snake.

* ⬆️ Up
* ⬇️ Down
* ⬅️ Left
* ➡️ Right

### 2. Touch Screen Mode

Control the snake through touch interaction with the game screen.

### 3. Tap & Rotate

A different control mechanism based on tapping and rotating the direction of movement.

### 4. Button Control Mode

An alternative button-based control method for navigating the snake.

---

## 🎨 Customizable Colors

SnakeX includes a customizable color system that allows players to change the appearance of the game.

This feature was implemented to make the game more interactive and give users control over its visual style.

## 🚀 Getting Started

### Prerequisites

Make sure you have Flutter installed on your system.

You can verify your Flutter installation with:

```bash
flutter doctor
```

### Clone the Repository

```bash
git clone https://github.com/nahalmalik/SnakeX.git
```

Navigate to the project:

```bash
cd game/Snake-Game-Flutter-master
```

### Install Dependencies

```bash
flutter pub get
```

### Run the Application

Connect a supported device or start an emulator and run:

```bash
flutter run
```
